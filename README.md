# PyYouTubeDownloader

Youtube MP3/MP4 Downloader Using Python.

## Usage

1. Download Code
   
```bash
git clone https://github.com/DelfinIbnKadafi/PyYouTubeDownloader.git
```

2. Open Folder

```bash
cd PyYouTubeDownloader
```

3. Run Code

```bash
python main.py
```

## Requiremennts

Python 3.x
